# entities — 人・組織・もの

「固有名詞で呼べる対象」を1つ1ファイルで置きます。

- 人（クライアント、担当者、同業者、講師）
- 会社・団体
- ツール・サービス・API
- 案件・プロジェクト
- 媒体（メディア、プラットフォーム）

## 書式

```markdown
---
type: entity
category: client | tool | person | project | media
updated: 2026-08-10
---

# 対象の名前

1行で「これは何か」。ここだけ読めば思い出せる粒度で書く。

## 分かっていること

- 事実を箇条書き。日付が分かるものは日付を添える [[daily/2026-08-10]]

## やり取りの経緯

- 2026-08-10 何があったか [[daily/2026-08-10]]

## 出典

- [[daily/2026-08-10]]
```

## 判断に迷ったら

- 固有名詞で呼べるなら entities、呼べない（考え方・やり方）なら concepts
- **登場したら作る。** 後でその名前で検索しそうな対象なら、初出でもページにする
- 例外は通りすがりの言及。「ついでに Slack で連絡した」の Slack にページは要らない
- 同じ対象のページを2つ作らない。作る前に必ず既存のファイル名を確認する
